# BetterKit 0.1.0

- Smooth scrolling for mouse wheels, with per-app exceptions.
- HiDPI on non-Retina displays through a virtual display, plus DDC brightness and contrast.
- Vietnamese typing (Telex, VNI, Simple Telex) powered by the uvie engine.
- Fan monitoring and control with a privileged helper that restores automatic mode when BetterKit quits.
- Guided permission setup and launch on login.
